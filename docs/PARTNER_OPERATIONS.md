# LinkedLab partner programme — manual operations

This is the operational checklist for the first version of the partner programme. Do not commit personal applicant or client data to this public repository.

## One-time setup

1. Submit a test application from each language page.
2. FormSubmit will send an activation message to `linkedlab.info@gmail.com` after the first submission. Confirm it once.
3. Send another test application and verify the message, language, referral field and redirect.
4. Copy `partner-register-template.csv` to a private spreadsheet. Store that working copy outside the public repository.

## Approve a partner

1. Review the applicant personally and answer from `linkedlab.info@gmail.com`.
2. Create a unique code using 2–32 letters, numbers, `_` or `-`, for example `ANNA24`.
3. Add the partner to the private register and send one or more links:
   - `https://linkedlab.eu/de/kontakt/?ref=ANNA24`
   - `https://linkedlab.eu/en/contact/?ref=ANNA24`
   - `https://linkedlab.eu/es/contacto/?ref=ANNA24`
4. Confirm the payout method and any invoice or tax-document requirements before activation.

## Validate a referral

1. Check that the code arrived in the WhatsApp message or enquiry record.
2. Confirm that the client is new and has not already been attributed to another partner.
3. Record the lead and partner code in the private register.
4. Mark the commission as confirmed only after the client has accepted the project and the agreed payment has arrived.
5. Exclude cancelled or refunded projects.
6. Pay €50 per valid new client, stopping at 10 clients / €500 for each partner.

## Data handling

- Keep applications and the working commission register private and access-controlled.
- Delete unsuccessful applications when they are no longer needed, unless a legal retention reason applies.
- Keep payment and accounting evidence for the applicable statutory period.
- Do not use referral codes for advertising profiles or cross-site tracking.
